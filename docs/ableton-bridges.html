Ableton Live 12 · control-surface comparison

Ableton Control Bridges

Two Remote Scripts let outside programs drive Live: AbletonOSC and ableton-mcp. This page compares what each can reach and lays out how our command-line tool can use both, without the MCP server's telemetry.

At a glance

The two bridges

AbletonOSC

UDP 11000 in · 11001 replies
What it is
A Remote Script that exposes Live's object model as OSC addresses, e.g. /live/song/set/tempo 120.
Surface
About 260 addresses across song, track, clip, clip slot, device, scene and view.
Strengths
Mixer, scenes, recording, undo, clip properties, and live listeners that push changes as they happen.
Gaps
Can't load instruments or effects from the browser, copy clips into the Arrangement, import audio files, or map rack macros.
Network
Local only. No telemetry.
License
MIT · ideoforms/AbletonOSC

ableton-mcp

TCP 127.0.0.1:9877 · JSON
What it is
A Remote Script that accepts JSON commands such as {"type":"set_tempo"}, plus a Python MCP server that wraps them as 37 tools for Claude and Cursor.
Surface
37 MCP tools; the Remote Script accepts about 40 commands, some of which the MCP server never exposes.
Strengths
Loads instruments, effects and drum kits from the browser, builds the Arrangement, imports audio files, works with racks.
Gaps
No mixer setters (volume, pan, mute, solo, sends), scenes, undo or recording.
Network
The Remote Script is local only. The Python MCP server sends telemetry to Supabase by default.
License
MIT · ahujasid/ableton-mcp · 3.3k stars

Read before installing

What to watch out for in ableton-mcp

Telemetry and data collection live in the Python MCP server

  • Anonymous telemetry is on by default. It sends an install ID, which tools ran, whether they succeeded and how long they took to Supabase. Turn it off with ABLETON_MCP_DISABLE_TELEMETRY=true.
  • Dataset recording is opt-in. When enabled it uploads prompts, MIDI notes, track and clip names and device settings, which may be published in an open training dataset.
  • Every tool takes a user_prompt argument. The assistant is asked to pass your original request into each call so it can be recorded.
  • Six tools exist only for that dataset: set_dataset_consent, submit_intent, rate_last_action, prefer_candidate, reject_last_action, record_audition.
  • The Remote Script itself makes no internet connections. It listens on 127.0.0.1 only. Anything on your machine that reaches port 9877 can control Live, including importing files by path, so keep it on localhost.
Integration plan

What we build into our CLI

  1. A backend router

    Every command declares the backend it needs. OSC handles the everyday surface; the TCP socket handles the browser, Arrangement, audio import and racks. If a script isn't loaded, the command says which one and how to enable it.

  2. Browser and device loading

    The biggest gap in AbletonOSC, filled from the ableton-mcp script.

    browser treebrowser searchdevice loaddrums load

  3. Arrangement building

    Copy Session clips onto the timeline at a beat and drop named locators, so a song structure can be laid out from a script.

    clip to-arrangementlocator addarrangement clips

  4. Rack macros

    Expose the two commands the MCP server leaves hidden: list a rack's nested devices, and map every nested Dry/Wet to Macro 1.

    rack inspectrack map-macro

  5. Snapshot and diff

    Save the whole project state to JSON before a batch of changes, then diff it afterwards to see exactly what moved. Useful before letting an agent loose on a set.

    snapshot savesnapshot diff before.json

  6. A safe notes set

    ableton-mcp's note writes only append. Replacing a clip's notes means reading them first, clearing, then writing, with the old notes kept so the change can be reverted.

    notes set --from notes.jsonnotes restore

  7. doctor

    Checks that both scripts answer, that their versions are ones the CLI knows, and that the MiniLab_3 slot is untouched.

  8. Left out on purpose

    The six dataset tools and the user_prompt argument. Nothing in the CLI sends data off your machine.

Both scripts go in Documents\Ableton\User Library\Remote Scripts. The ableton-mcp script can be copied straight from its repository; its Python MCP server doesn't need to be installed at all.

Open decision

One backend or two?

Recommended

Both backends

  • Covers everything in the matrix above.
  • Load instruments, effects and kits from the command line.
  • Two Remote Scripts to install and keep updated.
  • Uses two Control Surface slots.

AbletonOSC only

  • One script, one slot, a simpler setup.
  • Full mixer, scene, recording and listener control.
  • No loading instruments or effects from the browser.
  • No Arrangement building or audio import.
